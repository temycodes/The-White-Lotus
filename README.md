## White Lotus — Hotel Management Dashboard🏨

White Lotus is a modern hotel management web application built to manage day-to-day hotel operations in a clean, calm, data-focused interface. It is designed as an internal tool for staff and admins to track bookings, guests, stays, and revenue without unnecessary noise.

The app focuses on clarity, speed, and reliability while handling real-world hotel workflows.

>

## Features🛠

## Authentication & Access Control🔒

- Secure authentication powered by Supabase
- Protected routes for authenticated users only
- Session persistence and role-aware navigation

## Dashboard & Analytics💹

- Revenue and booking trends visualized with charts
- Stay duration breakdowns and daily activity summaries
- At-a-glance stats for quick operational insight

## Bookings & Guests📚

- Create, read, update, and delete bookings
- Manage guest information and stay details
- Check-in and check-out flows built for daily use

## Cabins & Rooms🗄

- Manage rooms with availability, pricing, and capacity
- Image uploads and updates
- Clean CRUD flows with instant UI feedback

## Data Management

- Server state handled with React Query
- Optimistic updates for a fast, responsive feel
- Automatic caching, refetching, and error handling

## Error Handling

- Graceful error boundaries
- Friendly fallback UI when something goes wrong
- Stable auth state even after recoverable errors

>

## Tech Stack

## Frontend

- React
- Styled Components
- React Router
- Context API
- Custom Hooks

## State & Data

- React Query for server state
- Local UI state via Context and hooks

## Backend

- Supabase (Auth, Database, Storage)
- Row Level Security for safe data access

## Charts & UI📊

- Recharts for data visualization
- Design tokens and surface-based theming
- Responsive, dashboard-first layout
